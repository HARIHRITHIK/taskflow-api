# 📸 TaskFlow API Screenshots

This directory stores real screenshots of the application displayed in the root `README.md`.

---

## 🖼️ Expected Image Files

To display screenshots in the repository `README.md`, upload the following two image files to this directory:

1. `dashboard.png` — Screenshot of the **TaskFlow Interactive Dashboard** (Streamlit Web UI).
2. `swagger.png` — Screenshot of the **Interactive Swagger UI Documentation** (`/docs`).

---

## 📤 How to Upload Directly via GitHub Web UI

1. Open your repository on GitHub: **[https://github.com/HARIHRITHIK/taskflow-api](https://github.com/HARIHRITHIK/taskflow-api)**.
2. Navigate to the `assets/screenshots/` folder.
3. Click **Add file** $\rightarrow$ **Upload files**.
4. Drag and drop your screenshots named exactly `dashboard.png` and `swagger.png`.
5. Click **Commit changes**.

Once uploaded, the images will automatically render in the root `README.md` and `DEMO.md`!
